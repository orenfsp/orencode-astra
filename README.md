# Цифровая платформа ФСП Оренбургской области

Веб-платформа для управления спортивным программированием в Оренбургской области. Она объединяет спортсменов, тренеров, судей и федерацию в одной системе для работы с соревнованиями, результатами, разрядами и отчётами.

> Проект находится на этапе подготовки. Описанные ниже возможности и структура являются целевыми и будут реализованы по мере разработки.

## Возможности

- Личные кабинеты федерации, спортсмена, тренера и судьи.
- Несколько ролей у одного аккаунта с переключением между кабинетами.
- Реестр спортсменов, тренеров, судей и организаций.
- Календарь соревнований, положения, заявки и модерация.
- Привязка тренера к спортсмену с подтверждением спортсменом.
- Назначение судейской коллегии.
- Ввод результатов, формирование протоколов и история выступлений.
- Заявки на спортивные разряды и судейские категории, контроль сроков.
- Рейтинг спортсменов и формирование сборной региона.
- Отчёт о численности занимающихся с экспортом в Excel.
- Формирование протоколов, отчётов и других документов.
- Уведомления в кабинете и Telegram.

Платформа рассчитана на шесть дисциплин: алгоритмическое и продуктовое программирование, программирование систем информационной безопасности, систем искусственного интеллекта, робототехнику и беспилотные авиационные системы.

## Технологии

**Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/ui, React Router, TanStack Query, React Hook Form, Zod, TanStack Table, Recharts.

**Backend:** Python, FastAPI, Pydantic, SQLAlchemy, Alembic.

**Данные и документы:** PostgreSQL, openpyxl, python-docx, WeasyPrint.

**Авторизация и уведомления:** серверные cookie-сессии, Argon2id, проверка ролей и разрешений, CSRF-защита, aiogram, Telegram Bot API, APScheduler.

**Запуск и проверки:** Docker, Docker Compose, Nginx, pytest, httpx, Playwright, GitHub Actions.

## Как устроено приложение

Браузерное приложение обращается к REST API на FastAPI. Backend проверяет входные данные, права пользователя и правила предметной области, затем читает или изменяет данные в PostgreSQL. Frontend и backend используют API-контракт OpenAPI.

```text
Браузер
  └── React + TypeScript
        └── REST API
              └── FastAPI
                    ├── PostgreSQL
                    ├── Генерация документов
                    └── Уведомления в Telegram
```

Backend организован как модульный монолит: единое приложение с отдельными модулями пользователей, соревнований, заявок, результатов, разрядов, рейтинга, отчётов и уведомлений.

## Структура проекта

```text
fsp/
├── backend/
│   ├── app/
│   │   ├── core/             # настройки, подключение к БД, авторизация
│   │   ├── modules/          # предметные модули API и бизнес-логики
│   │   └── main.py           # приложение FastAPI
│   ├── alembic/              # миграции базы данных
│   └── tests/                # тесты backend
├── frontend/
│   └── src/
│       ├── app/              # запуск приложения и маршруты
│       ├── pages/            # страницы кабинетов
│       ├── features/         # действия пользователя
│       ├── entities/         # модели предметных сущностей
│       └── shared/           # компоненты и API-клиент
├── docs/                     # документация архитектуры и API
├── scripts/                  # вспомогательные команды и демо-данные
├── compose.yaml              # локальный запуск сервисов
└── README.md
```

## Локальный запуск

Инструкция будет добавлена после создания приложения и конфигурации Docker Compose. В проекте будут предусмотрены файл `.env.example`, миграции базы данных и команда для заполнения демонстрационными данными.

## Демонстрационные данные

Для разработки и демонстрации используются только вымышленные персональные данные.
