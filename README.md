# Цифровая платформа ФСП Оренбургской области

Единая платформа регионального отделения Федерации спортивного программирования: реестр спортсменов, тренеров, судей и организаций, календарь соревнований, заявки, протоколы, разряды и судейские категории, рейтинг и сборная, отчёты. Платформа рассчитана на все шесть дисциплин вида спорта.

> Все персональные данные в демонстрационной версии вымышлены.

| **Заявки от тренера** за привязанных спортсменов с той же проверкой возраста и дисциплины; сводка заявок, разрядов и выступлений подопечных | `/competitions/:id` и `/cabinet` в роли тренера |
| **Судейская коллегия:** федерация назначает судей на соревнование с должностью; судья видит назначения, свои соревнования, категорию и срок её действия | `/admin/competitions/:id` → «Судейская коллегия»; `/cabinet` в роли судьи |
| **Заявки на судейскую категорию** (присвоение / подтверждение) с обоснованием; федерация фиксирует категорию, приказ и срок действия; реестр судей | `/cabinet` (судья), `/admin/judges` |
| **Заявки на разряд** от тренера или от спортсмена без тренера с указанием соревнования и результата-основания; федерация фиксирует разряд: дата, приказ, срок действия | `/cabinet`, `/admin/ranks` |
| **Подсветка кандидатов на разряд:** по опубликованным протоколам и ориентирам ЕВСК платформа показывает спортсменов, чей результат может соответствовать разряду выше текущего | `/admin/ranks` → «Кандидаты по протоколам» |
| **Контроль сроков** по ролям: спортсмену и тренеру — приём заявок и срок разряда, судье — срок категории, федерации — все сроки, включая ходатайства на премии Губернатора (до 1 февраля) | `/cabinet` → «Сроки», `/admin` |
| **Дашборд федерации:** показатели (занимающиеся, соревнования, участники, разряды), «требует внимания», ближайшие соревнования и сроки | `/admin` |
| **Уведомления** в кабинете (колокольчик в шапке) и на email: открытие приёма заявок, решения по заявкам, публикация протокола, запросы тренеров, заявки на разряд и категорию, назначение судьи, напоминания об истечении сроков. Email можно отключить в кабинете | `/notifications`; письма — в Mailpit http://localhost:8025 |

**Сквозной сценарий для демонстрации:** федерация создаёт соревнование с открытым приёмом заявок → спортсмен заполняет профиль и подаёт заявку → федерация одобряет её → вносит баллы → публикует протокол → результат появляется в истории спортсмена.

Возраст для допуска считается по году рождения: сколько лет спортсмену исполняется в календарном году соревнования.

Напоминания о сроках создаёт фоновая задача backend (раз в 6 часов, без дублей); федерация может запустить её вручную: `POST /api/v1/admin/reminders/run`. Ориентиры ЕВСК для подсветки кандидатов заполнены значениями по умолчанию — федерация сверяет их с действующей ЕВСК и правит через `PUT /api/v1/rank-norms`.

Следующие этапы: рейтинг и сборная, реестр занимающихся и отчёт о численности, документы по формам (протокол, отчёт по спортсмену), журнал действий, демо-данные за 2 года по всем дисциплинам.

## Технологии

- **Frontend:** React 19, TypeScript, Vite, React Router.
- **Backend:** Python 3.12, FastAPI, Pydantic, SQLAlchemy 2 (async), Alembic.
- **Данные:** PostgreSQL 17.
- **Безопасность:** серверные cookie-сессии, Argon2id, CSRF double-submit, проверка ролей на сервере, ограничение попыток входа. Подробнее — [docs/auth-mvp.md](docs/auth-mvp.md).
- **Запуск и проверки:** Docker Compose, unittest + httpx (SQLite и PostgreSQL).

## Локальный запуск

Нужны Docker Desktop и Node.js 20+.

```bash
cp .env.example .env
docker compose up -d --build
```

Backend поднимется на http://127.0.0.1:8002 (документация API — http://127.0.0.1:8002/docs), почтовый ящик для писем-уведомлений Mailpit — на http://localhost:8025. При старте контейнер применяет миграции и заполняет демо-данные: справочники, организации и соревнования по всем шести дисциплинам.

Администратор федерации создаётся явной командой (пароль 12–128 символов):

```bash
docker compose exec -e ADMIN_EMAIL="admin@example.test" -e ADMIN_PASSWORD="replace-with-a-long-local-password" backend python -m app.create_admin
```

Frontend:

```bash
cd frontend
npm ci
npm run dev
```

Откройте http://localhost:5173. Адрес API задаётся переменной `VITE_API_URL` (см. `frontend/.env.example`).

### Тесты

```bash
docker compose --profile test run --rm backend-test
```

Без Docker (SQLite):

```bash
cd backend
python -m venv .venv && .venv/Scripts/pip install -e ".[dev]"
.venv/Scripts/python -m unittest discover -s tests
```

## Модель данных

- `users`, `roles`, `user_roles`, `auth_sessions` — аккаунт, назначенные роли, сессии с активной ролью; `users.pd_consent_at` — согласие на обработку ПД.
- `profiles` — общие данные человека (ФИО, дата рождения, пол, муниципалитет).
- `athlete_profiles` + `athlete_disciplines` — данные спортсмена, дисциплины, организация (NULL — «без организации»), законный представитель, РУСАДА.
- `coach_profiles` — данные тренера.
- Справочники: `disciplines`, `competition_types`, `age_groups`, `municipalities`, `organizations`, `judge_positions`.
- `competitions` + `competition_age_groups` — соревнование со ссылками на справочники, уровень, формат, календарный план и номер, файл положения, время публикации протокола.
- `applications` — заявка спортсмена: соревнование, возрастная группа, кто и из какой роли подал, статус (на модерации / одобрена / отклонена / отозвана), решение федерации. Одна заявка на спортсмена в соревновании.
- `results` — результат по одобренной заявке: баллы, итог (результат / не явился / дисквалифицирован), рассчитанное место.
- `coach_links` + `coach_link_events` — связь тренер — спортсмен по дисциплине со статусом и историей изменений.
- `judge_profiles`, `judge_category_requests`, `judge_assignments` — категория судьи со сроком и приказом, заявки на категорию, назначения в судейские коллегии с должностью.
- `rank_requests`, `athlete_ranks`, `rank_norms` — заявки на разряд с результатом-основанием, присвоенные разряды (дата, приказ, срок), ориентиры ЕВСК для подсветки кандидатов.
- `notifications` — уведомления в кабинете, отметка о прочтении и отправке на email; `users.email_notifications` — настройка внешнего канала.

Правило календарных планов проверяется на сервере: региональные соревнования включаются в план Оренбургской области, межрегиональные и всероссийские — в ЕКП Минспорта России.

## API

Все маршруты — под `/api/v1`, полная схема — в OpenAPI (`/docs`).

| Метод и путь | Доступ | Назначение |
| --- | --- | --- |
| `POST /auth/register`, `POST /auth/login`, `POST /auth/logout`, `GET /auth/me` | — | Аккаунт и сессия |
| `POST /auth/role` | вход + CSRF | Переключить активную роль |
| `POST /auth/roles` | вход + CSRF | Добавить себе роль спортсмена, тренера или судьи |
| `GET /reference` | публично | Все справочники одним запросом |
| `POST/PUT /reference/competition-types`, `/age-groups`, `/organizations` | федерация | Пополнение справочников |
| `GET /me/profile`, `PUT /me/profile` | вход | Личные данные |
| `PUT /me/athlete`, `PUT /me/coach` | активная роль | Данные спортсмена и тренера |
| `GET /competitions`, `GET /competitions/{id}` | публично | Календарь с фильтрами `discipline_id`, `level`, `age_group_id`, `calendar_plan`, `status`, `q` |
| `POST /competitions`, `PATCH /competitions/{id}`, `PATCH /competitions/{id}/status`, `POST /competitions/{id}/close-registration`, `POST /competitions/{id}/archive` | федерация | Управление календарём |
| `PUT /competitions/{id}/regulation`, `GET /competitions/{id}/regulation` | федерация / публично | Положение соревнования |
| `GET /competitions/{id}/eligibility` | вход | Проходит ли спортсмен по возрасту и дисциплине, в какую группу |
| `POST /competitions/{id}/applications` | спортсмен | Подать заявку |
| `GET /me/applications`, `POST /applications/{id}/withdraw` | спортсмен | Мои заявки, отзыв |
| `GET /me/results` | спортсмен | История выступлений |
| `GET /competitions/{id}/applications`, `POST /applications/{id}/decision` | федерация | Модерация заявок |
| `PUT /competitions/{id}/results` | федерация | Внести или исправить результаты, места пересчитываются |
| `GET /competitions/{id}/protocol` | публично после публикации | Протокол по возрастным группам |
| `POST /competitions/{id}/protocol/publish`, `/unpublish` | федерация | Публикация протокола |
| `GET /coach/athletes/search`, `GET/POST /coach/links`, `POST /coach/links/{id}/status` | тренер | Поиск в реестре, запрос на привязку, смена статуса связи |
| `GET /me/coach-links`, `POST /me/coach-links/{id}/respond` | спортсмен | Подтвердить или отклонить тренера |
| `GET /coach/athletes`, `GET /coach/applications`, `GET /coach/rank-requests` | тренер | Сводка по подопечным |
| `GET /me/judge`, `POST /me/judge/requests` | судья | Категория, назначения, заявка на категорию |
| `GET /judges`, `GET /judge-requests`, `POST /judge-requests/{id}/decision` | федерация | Реестр судей, решения по категориям |
| `GET/POST /competitions/{id}/judges`, `DELETE /competitions/{id}/judges/{assignment_id}` | федерация | Судейская коллегия |
| `GET /me/rank`, `POST /rank-requests` | спортсмен / тренер | Разряд и заявка на разряд |
| `GET /rank-requests`, `POST /rank-requests/{id}/decision`, `GET /rank-candidates`, `GET /ranks/expiring`, `GET/PUT /rank-norms` | федерация | Разряды, кандидаты по ЕВСК, истекающие |
| `GET /me/deadlines` | вход | Сроки для активной роли |
| `GET /admin/dashboard`, `POST /admin/reminders/run` | федерация | Дашборд, запуск напоминаний |
| `GET /me/notifications`, `GET /me/notifications/unread-count`, `POST /me/notifications/read`, `GET/PUT /me/settings` | вход | Уведомления и настройка email |
