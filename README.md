# Цифровая платформа ФСП Оренбургской области

Единая платформа регионального отделения Федерации спортивного программирования Оренбургской области: реестр спортсменов, тренеров, судей и организаций, календарь соревнований с заявками и протоколами, разряды и судейские категории со сроками, рейтинг и сборная региона, отчёты и документы. Покрыты все шесть дисциплин вида спорта: алгоритмическое и продуктовое программирование, программирование систем информационной безопасности, систем искусственного интеллекта, робототехники и беспилотных авиационных систем.

Решение кейса хакатона «ОренКод 2026».

> Все персональные данные в демонстрационной версии вымышлены.

**Стек:** React 19 + TypeScript + Vite (сайт), Python 3.12 + FastAPI + SQLAlchemy 2 + Alembic (API), PostgreSQL 17, python-docx и openpyxl (документы .docx и .xlsx), nginx, Docker Compose, Mailpit (почта для демо).

## Запуск у себя на компьютере

Нужны только **Git** и **Docker**. Node.js, Python и PostgreSQL ставить не нужно — всё собирается внутри контейнеров.

### 1. Установите Docker и Git

| Система | Что установить |
| --- | --- |
| Windows 10/11 | [Docker Desktop](https://www.docker.com/products/docker-desktop/) (при установке оставьте включённым WSL 2) и [Git for Windows](https://git-scm.com/download/win). После установки перезагрузите компьютер и запустите Docker Desktop — дождитесь надписи «Engine running». |
| macOS | [Docker Desktop](https://www.docker.com/products/docker-desktop/) и Git (`xcode-select --install`). Запустите Docker Desktop. |
| Linux | Docker Engine и плагин Compose ([инструкция](https://docs.docker.com/engine/install/)), Git из пакетного менеджера. |

Проверка — обе команды должны напечатать версии:

```bash
docker compose version
git --version
```

### 2. Скачайте проект

```bash
git clone https://github.com/orenfsp/orencode-astra.git
cd orencode-astra
```

### 3. Запустите

```bash
docker compose up -d --build
```

Первая сборка занимает 3–7 минут (скачиваются образы PostgreSQL, Python, Node.js и nginx). При старте backend сам создаёт таблицы (миграции Alembic), заполняет справочники и загружает демо-данные — ещё около 30 секунд.

Проверить, что всё поднялось:

```bash
docker compose ps
```

Должны работать четыре сервиса: `db`, `backend`, `frontend`, `mailpit`. Готовность backend видна в журнале — строка `Application startup complete`:

```bash
docker compose logs backend
```

### 4. Откройте в браузере

| Что | Адрес |
| --- | --- |
| **Платформа** | http://localhost:8080 |
| Документация API (OpenAPI) | http://localhost:8002/docs |
| Почтовый ящик с письмами-уведомлениями (Mailpit) | http://localhost:8025 |

Войдите любым демо-аккаунтом из раздела [«Демо-данные»](#демо-данные).

Файл настроек `.env` создавать не обязательно: без него используются значения по умолчанию. Чтобы что-то поменять (порты, пароль демо-аккаунтов, SMTP), скопируйте пример и отредактируйте его:

```bash
cp .env.example .env
```

В PowerShell вместо `cp` — `Copy-Item .env.example .env`. После изменения `.env` перезапустите: `docker compose up -d`.

### Остановка, обновление, сброс

```bash
docker compose stop                # остановить, данные сохранятся
docker compose up -d               # запустить снова
git pull && docker compose up -d --build   # обновить до новой версии
docker compose down -v             # удалить контейнеры и все данные (база, загруженные файлы)
```

После `docker compose down -v` и повторного `docker compose up -d --build` база создаётся заново с демо-данными. Чистая база без демо-данных — `DEMO_DATA=0` в `.env` (на уже заполненной базе сначала `docker compose down -v`).

### Если что-то не запускается

| Симптом | Что сделать |
| --- | --- |
| `Cannot connect to the Docker daemon` / `error during connect` | Docker Desktop не запущен — запустите его и дождитесь «Engine running». |
| `port is already allocated` / `address already in use` | Порт занят другой программой. Задайте свободный в `.env`: `FRONTEND_PORT` (8080), `BACKEND_PORT` (8002), `MAILPIT_PORT` (8025), `POSTGRES_PORT` (5433). Если меняете `FRONTEND_PORT`, поменяйте на тот же порт и `APP_URL` — по нему строятся ссылки в письмах и QR-кодах справок. |
| Сайт открывается, но «Не удалось загрузить» / ошибка 502 | Backend ещё загружает демо-данные — подождите полминуты. Ошибки смотрите в `docker compose logs backend`. |
| На Windows сборка падает с ошибкой WSL | Обновите WSL командой `wsl --update` в PowerShell от администратора и перезапустите Docker Desktop. |
| Нужен собственный администратор | `docker compose exec -e ADMIN_EMAIL="admin@example.test" -e ADMIN_PASSWORD="длинный-пароль-от-12-символов" backend python -m app.create_admin` — команда создаёт аккаунт или выдаёт роль федерации существующему. |

### Режим разработки (по желанию)

Для правок интерфейса с мгновенной перезагрузкой нужен Node.js 20+. Backend, база и почта остаются в Docker, сайт запускается через Vite — он сам проксирует `/api` на backend (`http://127.0.0.1:8002`, другой адрес задаётся переменной `BACKEND_URL`):

```bash
docker compose up -d db mailpit backend
cd frontend
npm ci
npm run dev
```

Сайт откроется на http://localhost:5173.

Тесты backend (72 теста: API, права ролей, протоколы, документы) — на PostgreSQL в Docker, вместе с проверкой миграций (`alembic check`) и загрузкой демо-данных:

```bash
docker compose --profile test run --rm --build backend-test
```

Без Docker, на SQLite (нужен Python 3.12):

```bash
cd backend
python -m venv .venv
.venv/Scripts/pip install -e ".[dev]"            # Linux/macOS: .venv/bin/pip
.venv/Scripts/python -m unittest discover -s tests   # Linux/macOS: .venv/bin/python
```

Проверка типов и сборка фронтенда: `cd frontend && npm ci && npm run build`. Те же проверки запускает GitHub Actions на каждый push.

Для работы в интернете включите HTTPS на reverse proxy и задайте `AUTH_COOKIE_SECURE=true`, свой `ADMIN_REGISTRATION_CODE`, пароли PostgreSQL и `DEMO_DATA=0`.

## Правила вида спорта в платформе

- Возраст для допуска определяется по году рождения в календарном году соревнования.
- Региональные соревнования включаются в календарный план Оренбургской области, межрегиональные и всероссийские — в ЕКП Минспорта России (проверяется на сервере).
- Протоколы — по рекомендуемым образцам из Приложения № 5 к Правилам вида спорта «спортивное программирование» (приказ Минспорта России от 11.08.2023 № 584): по задачам — для программирования алгоритмического, робототехники, БАС, систем информационной безопасности (и систем ИИ), по оценкам судей — для продуктового программирования.
- Занимающийся учитывается в году, если начал занятия не позже и не прекратил их раньше этого года.
- Ориентиры ЕВСК для подсветки кандидатов на разряд и сроки действия по умолчанию заполнены типовыми значениями — федерация сверяет их с действующими нормами и меняет.
